📱 使用方法

PotPlayer / VLC 播放器

1

打开播放器，选择 打开链接（Ctrl+U）

2

粘贴 M3U 地址：
https://iptv.diynets.xyz/m3u

3

播放器自动加载频道列表，选择想看的频道

IPTV 客户端（TiviMate / IPTV Smarters）

1

添加播放列表，选择 M3U URL 方式

2

输入 TXT 地址：
https://iptv.diynets.xyz/txt

3

EPG 地址（可选，用于节目预告）：
https://iptv.diynets.xyz/epg/epg.xml

⚙️ 配置指南

频道管理

编辑 config/myanmar_sports.txt，按分类添加频道：

⚽ Sports,#genre#
CCTV-5
CCTV-5+
CCTV-16

📺 Chinese TV,#genre#
CCTV-1
CCTV-2

频道别名

编辑 config/alias.txt，将源中的不同名称映射到模板名：

CCTV-1 = CCTV-1综合,CCTV1综合,中央一套
CCTV-5 = CCTV-5体育,CCTV5体育,中央五套

订阅源管理

编辑 config/subscribe.txt，每行一个 IPTV 源 URL：

https://iptv-org.github.io/iptv/index.m3u
https://raw.githubusercontent.com/xxx/xxx/main/list.m3u

🔄 更新流程

手动更新频道路径

git pull
docker pull networkio/iptv-api:latest
docker stop iptv-api && docker rm iptv-api
docker run -d --name iptv-api --restart unless-stopped -p 5180:8080 \
  -v /home/pi5/iptv-api/config:/iptv-api/config \
  -v /home/pi5/iptv-api/user_output:/iptv-api/output \
  -e PUBLIC_DOMAIN=iptv.diynets.xyz -e PUBLIC_PORT=5180 \
  networkio/iptv-api:latest

GitHub Actions 自动构建

每次推送 feature/myanmar-sports-ui 分支时自动触发：

  1. 代码推送到 GitHub
  2. Actions 自动构建 Docker 镜像
  3. 推送到 Docker Hub（networkio/iptv-api:latest）
  4. 树莓派上执行 docker pull && docker restart

❓ 常见问题

Q: 频道播放不出来怎么办？

免费源可能不稳定，可以尝试：

  • 重新运行更新（GitHub Actions → Update schedule → Run workflow）
  • 切到另一个源（同一个频道有多个备用接口）
  • 在 subscribe.txt 中添加更多稳定源
Q: 如何添加新频道？

编辑 config/myanmar_sports.txt，在对应分类下添加频道名。如果源中的频道名不同，再在 alias.txt 中添加别名映射。

Q: 更新需要多长时间？

约 30-50 分钟，取决于订阅源数量和网络状况。测速已关闭，主要耗时在获取源和匹配频道。

Q: 如何查看运行日志？

网页访问：https://iptv.diynets.xyz/log/result

或命令行：docker logs iptv-api
